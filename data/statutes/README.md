# Local statute sources

Place English source files here as `bns.pdf`, `bnss.pdf`, `bsa.pdf`, and
`constitution.pdf`, or supply reviewed UTF-8 files with the same `.txt` basenames.
Text takes precedence when both formats exist. See the repository README for
official download sources, validation and ingestion commands. PDFs, extracted text,
and OCR intermediates stay local and are excluded from Git and Docker images.
